# 🌤️ Weather App

A real-time weather application built with HTML, CSS, and JavaScript that fetches data from the OpenWeatherMap API.

## Features
- 🔍 Search by city name
- 🌡️ Real-time temperature, humidity, and wind speed
- 🌆 Dynamic weather icons
- ⚠️ Error handling for invalid cities

## Tech Stack
- HTML5
- CSS3
- JavaScript (Async/Await, Fetch API)
- OpenWeatherMap API

## Live Demo
[View Live](https://niteshsingh-x.github.io/weather-app/)

## How to Run
1. Clone this repo
2. Open `index.html` in your browser
3. Enter your city name and click "Search"
